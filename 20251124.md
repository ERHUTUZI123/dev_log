# ```searchTerm``` Lifecycle

## 1. User types into SearchBar
```js
const [searchTerm, setSearchTerm] = useState('');

<input
  value={searchTerm}
  onChange={(e) => setSearchTerm(e.target.value)}
/>
````

Local SearchBar state updates with each keystroke.


## 2. User submits the form

```js
const onhandleSubmit = (e) => {
  e.preventDefault();
  if (searchTerm) {
    navigate(`/search/${searchTerm}`);
    setSearchTerm('');
  }
};
```

* URL becomes `/search/<term>`
* SearchBar's state resets to `""`


## 3. Router loads SearchFeed

```js
const { searchTerm } = useParams();
```

`searchTerm` now comes from the URL, not from the SearchBar component.


## 4. useEffect triggers API fetch

```js
useEffect(() => {
  fetchFromAPI("search", {
    part: "snippet",
    q: searchTerm,
    maxResults: 50,
  }).then((data) => setVideos(data.items));
}, [searchTerm]);
```

API is called using the URL’s `searchTerm`.


## 5. UI renders with results

```js
<Typography>
  Search results for <span>{searchTerm}</span>
</Typography>

<Videos videos={videos} />
```

Results shown based on URL-provided `searchTerm`.
