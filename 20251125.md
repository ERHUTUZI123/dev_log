runtime 400 error reported, since ```["snippet", "statistics"]``` will be sent as ```part[]=id&part[]=snippet```. It should be ```"snippet,statistics"```. Same as the ```["id", "snippet"]```.

After fixing to 
```
useEffect(() => {
fetchFromAPI("videos", {
    part: "snippet,statistics",
    id,
}).then((data) => setVideoDetail(data.items?.[0]));

fetchFromAPI("search", {
    part: "id,snippet",
    relatedToVideoId: id,
    type: "video",
    videoEmbeddable: "true",
    maxResults: 25,
})
    .then((data) => setVideos(data.items || []));
}, [id]);
```
